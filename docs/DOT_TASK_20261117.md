## 阶段 4：套餐与支付链路
对照规格第 3 节逐条核对 `screens/packages.dart`：
1. 套餐详情：价格区、套餐内容、使用规则、退款规则一行（来自接口字段，不可退时醒目提示且在下单页再提示一次）、适用门店、评价摘要、固定底部栏；库存 0 显示「已售罄」，已下架整页只留返回。
2. 下单页：数量步进器上限取 min(限购余量, 库存)；支付方式二选一，默认上次；须知勾选前按钮置灰；点「確認支付」后按钮 loading 且禁止重复点击。
3. 支付结果：每 2 秒轮询 `GET /orders/{id}` 最多 60 秒，期间显示「正在確認支付結果」，返回需确认；`paid` 显示成功页「套餐券已存入錢包」，按钮「查看券」「繼續逛」；`failed/timeout` 显示失败页，按钮「重新支付」「取消訂單」；pending 超 15 分钟显示「訂單已關閉」。客户端代码里不得出现向 confirm-payment 传 outcome。
4. 订单标签：全部/待支付/已支付/已退款；详情显示订单号、支付方式、时间、退款状态与金额、预计到账「1–3 個工作日原路退回」；不可退时隐藏「申請退款」按钮，不是置灰。
验收：截图成功、失败、超时、关闭四种结果页；断网重试一次。
