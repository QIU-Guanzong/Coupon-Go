# 評價管理與顧客評價（C7 / C8）

基線是 Coupon-Go #61 `f104acb5174131dd50f11297f6928e89160d8284`。前／後畫面以離線 Flutter 引擎在 390×844 繪製；使用正式字體和主題，門店、評價、結果均為測試記憶體資料。無真機或現網寫入。

- [繁中前後對照](overview-zh.webp)／[English before and after](overview-en.webp)：顧客頁顯示商戶回覆時間，窄屏篩選由溢出 24 px 改為可換行；商戶由舊的差評入口進入評價管理。
- [繁中商戶流程](operations-zh.webp)／[English merchant flows](operations-en.webp)：已回覆、編輯、發送成功、差評、填寫申訴、當次申訴紀錄。原本沒有對應流程，因此這兩張只附改後圖。

門店使用已上線的名單與權限規則。此版沿用現有公開評價分頁和回覆／申訴介面；篩選及待回覆數只涵蓋當頁，首頁角標僅統計已載入的首頁。「已申訴」只顯示本頁開啟期間由伺服器確認的申訴。不猜全店總數、不公開伺服器排除的評價。PUBLIC_TRIAL 維持唯讀。

現有回覆回傳 `replied_at`，按本地時區顯示。現網接口未提供 `coupon_name`、`redeemed_at`、首次回覆或編輯標記，因此缺值時不顯示，不拿評論時間代替。跨頁／跨店的準確待回覆、完整申訴紀錄、核銷與回覆修改資料、通知，由 R1/R2/R4/R5 後端批次處理。

本機驗證：`flutter analyze --no-pub lib test` 無問題；預設模組完整 Flutter 測試 288 通過、22 跳過；PUBLIC_TRIAL 定向 9 通過、4 跳過；前後每套 4 個 390×844 渲染用例均通過，舊版顧客頁按測試預期重現溢出。
