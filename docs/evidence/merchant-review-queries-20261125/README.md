# 評價管理：接通商戶評價與待回覆接口

基線：Coupon-Go #63 `6330ee98fe603dd8d843b1d0f5898ff1e64f3209`。前端沿用店主管理入口；伺服器授權與資料寫入不改。

- 首頁角標使用授權範圍內的實際待回覆總數；評價管理用該店全量待回覆數。接口不可用時省略未知值，不當成 0。
- 待回覆、已回覆、差評、已申訴、排序與翻頁由伺服器處理。切換篩選重回第 1 頁。獲授權門店的歷史申訴可查；已申訴的評價不提供再操作，也不在顧客頁公開。
- 未登入／無權限不改走公開接口。只有新列表接口 404 才降級回 #62 的現有公開列表，繼續標明本頁計數／當次申訴範圍。
- PUBLIC_TRIAL 保留原唯讀入口，不存取新私有接口，不更動網關允許清單。
