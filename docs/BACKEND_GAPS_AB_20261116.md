## 缺口

1. **GET /admin/orders 不存在**——后端只有用户侧 GET /orders。后台 v1/v2 的订单列表目前无对应接口。
2. **/nearby-shops 不返回评分/有券/有套餐/创建时间**——附近列表缺这四个字段，前端拿不到。
3. **评价「最有用」排序缺有用票字段**——无 helpful-vote 计数/标记字段，无法按最有用排序。
4. **星级分布缺服务端字段**——5/4/3/2/1 星分布计数没有接口字段。
5. **prepare_scan 不返回顾客手机号后四位与有效期**——预核销响应缺这两个字段。
6. **package-details / bargain-sessions / bargain-campaigns / orders 部分字段缺失**——前端已防御性隐藏，具体缺哪些字段见 UI_SPEC 与各页面代码，补之前先逐个接口核对。
7. **POST /packages/{id}/purchase 需支持 quantity**——目前只支持单件购买。

## 处理原则

- 每项先核对 UI_SPEC / 前端实际调用，再决定补接口还是改前端。
- 补接口时沿用现有命名与拼写习惯，不另起一套。
- 涉及金额/库存的补项走 FIX-3 同款行锁与唯一约束，不得裸加字段。
