# Coupon GO! UI 规格（交给 muse 开发）

范围：Flutter 端 `apps/mobile/lib/`，首批 4 个新界面 + 首页改版 + 钱包/商户端小改。后台管理界面见第 9 节。
前置：先完成修复单 FIX-1（支付确认）。UI 不再向服务端传支付结果，见 3.3。

## 0. 总原则
1. 沿用 `theme.dart` 现有主色、字体、圆角、阴影，不新增色板；新增的语义色只有三个，在 `theme.dart` 里集中定义：`moneyPositive`（可提现）、`moneyPending`（待确认）、`moneyVoid`（已失效），在浅色和深色下各给一组，对比度 ≥ 4.5:1。
2. 领券主路径不动：发现 → 领取 → 钱包 → 出示 → 核销。新模式只加入口，不改这条路径的步数。
3. 所有用户可见文案写成正式产品用语，不出现：模拟、测试、开发版、演示、暂未开放、coming soon、Stripe、sandbox、test_mode。没做完的功能隐藏入口，不放占位说明。
4. 金额统一 `HK$ 1,234.50`，两位小数，等宽数字（`FontFeature.tabularFigures`）。倒计时统一 `2天 3小时` / `03:12:45`（小于 24 小时用后者）。
5. 每个列表界面都要有 4 个状态：加载中（骨架屏，不用转圈）、空状态（一句话 + 一个动作按钮）、错误（一句话 + 重试）、正常。错误文案不讲实现，例如「网络不稳定，请重试」。
6. 点击区域 ≥ 44×44 逻辑像素；所有图标按钮加 `Semantics` 标签；二维码页支持系统字体放大到 200% 不溢出。
7. 所有价格、状态以服务端返回为准，客户端不自己算钱（返现金额、退款金额、砍后价都直接显示接口字段）。

## 1. 导航
【2026-11-16 修订】底部保留现有 5 个入口：主頁 / 收藏 / Let's Go! / 限時 / Q Wallet。返现并入 Q Wallet 第四个标签，附近并入 Let's Go! 的标签，砍价承载在「限時」。原「首页/附近/钱包/返现/我的」作废；第 5、6、8 节里提到的底部入口按下方第 12 节映射理解。
- 套餐、砍价从首页进入，也可从商户详情页进入，不占底部入口。
- 商户端和后台角色登录后沿用现有商户端界面，不出现返现和砍价入口。
- 未登录用户可浏览首页、附近、套餐详情、砍价详情（只读）；点「购买 / 砍一刀 / 提现」时再弹登录，登录后回到原界面。

## 2. 首页改版（`screens/customer.dart`）
自上而下：
1. 搜索栏（占位「搜索商户或优惠」）+ 定位城市/区域芯片。
2. 分类横滑（餐饮、咖啡、美容、娱乐…，沿用现有数据）。
3. 「限时砍价」横滑卡片区：卡片 160×200，显示商户图、套餐名、当前价（大）、底价（小，灰）、剩余时间。最多 6 张，末尾「查看全部」。无进行中活动时整块不显示。
4. 「热门套餐」：2 列网格卡片，图、名称、套餐价、原价划线、已售数。
5. 「附近优惠」：纵向列表，沿用现有领券卡片，右下加距离。
6. 券卡片的按钮文案保持「领取」，套餐卡片是「立即抢购」，砍价卡片是「去砍价」，三者样式不同（领取=描边，抢购=实心主色，砍价=强调色实心）。

接口：沿用 `/home` 系列；套餐 `GET /packages`；砍价活动列表见 4.1。

## 3. 套餐（`screens/packages.dart`）
### 3.1 套餐详情页
- 顶部轮播图（≤ 6 张）。
- 价格区：套餐价（大号、主色）、原价划线、「省 HK$X」、已售数。
- 「套餐内容」：每行 菜品名 / 份数 / 单价，底部合计。
- 「使用规则」：有效期（精确到日）、可用时段、是否需预约、每人限购、是否可叠加。
- 「退款规则」固定放价格区下方，一行字，来自接口字段，默认「未使用随时可退，过期自动退款」。如果该套餐被商户标为不可退，显示「该套餐售出后不可退」并在购买页再次醒目提示一次；不允许隐藏。
- 「适用门店」：门店数 + 点击展开列表（地图跳转）。
- 「评价」：评分汇总（总分 + 三维分）、最新 3 条，点进评价列表。
- 底部固定栏：左侧价格，右侧「立即抢购」。库存为 0 时按钮置灰显示「已售罄」；已下架整页显示「该套餐已下架」并只留返回按钮。
接口：`GET /package-details?package_id=`。

### 3.2 下单页
- 套餐摘要（图、名称、数量步进器，上限取 min(限购余量, 库存)）。
- 支付方式二选一：转数快 FPS / 信用卡，默认上次使用的。
- 金额明细：套餐价 × 数量 = 合计。
- 勾选项：「我已阅读并同意购买须知」，须知页内含退款规则；未勾选按钮置灰。
- 主按钮「确认支付 HK$X」。点击后按钮进入 loading，禁止重复点击（防双击下单）。
接口：`POST /packages/{id}/purchase`，返回订单与支付信息。

### 3.3 支付与结果（重点）
- 客户端不再调用 `confirm-payment` 传 outcome。支付由支付 SDK/跳转完成后，客户端每 2 秒轮询 `GET /orders/{id}`，最多 60 秒，直到 `payment_status` 为 `paid / failed / timeout`。
- 轮询期间显示「正在确认支付结果」，不可返回（返回按钮弹确认：「支付可能仍在处理，确定离开？」；离开后订单在「我的订单」里继续显示状态）。
- paid：成功页，显示券图标、「套餐券已存入钱包」、按钮「查看券」「继续逛」。
- failed / timeout：失败页，一句原因 + 「重新支付」（`retry-payment`）和「取消订单」（`cancel`）。
- 订单 pending 且已超 15 分钟（以服务端为准）显示「订单已关闭」。

### 3.4 我的订单 / 退款
- 订单列表按 全部 / 待支付 / 已支付 / 已退款 分 Tab。
- 订单详情显示订单号、支付方式、支付时间、退款状态与金额、预计到账（「1–3 个工作日原路退回」）。
- 「申请退款」仅在券未核销且在可退条件内显示；点击弹确认「退款后套餐券作废，确定吗？」。不可退时按钮隐藏，不是置灰加说明。
接口：`GET /orders`、`GET /orders/{id}`、`POST /orders/{id}/refund`。

## 4. 砍价（`screens/bargain.dart`）
### 4.1 列表
首页「查看全部」进入，2 列卡片，同首页卡片，加「已有 N 人在砍」。
### 4.2 活动详情（发起前）
- 大图、名称、原价、当前最低可砍到的底价（醒目）、规则 3 行图示：「付款后发起 → 分享给好友助力 → 价格降到底价或时间到，差额自动退回」。
- 说明库存「数量有限，先到先得」，显示剩余库存数。
- 按钮「立即发起砍价」，需登录与预付（预付金额显示在按钮上方：「先付 HK$X，砍价差额自动退回」）。
### 4.3 我的砍价（核心界面）
- 圆环或横向进度条：从原价到底价，已砍多少、还差多少，数字取接口字段。
- 倒计时（距结束）。
- 助力列表：头像（匿名则首字）、砍了多少、时间；空时显示「分享给好友，每人帮你砍一刀」。
- 主按钮「分享给好友」（调用系统分享，链接为活动邀请链接）；次按钮「现在购买」（以当前价结算，购买后差额退回，退款金额在确认页明示）。
- 终态：
  - 成功（达底价或手动购买）：显示「已购买，套餐券在钱包」+ 退款明细（金额、预计到账）。
  - 未成团/过期：「砍价已结束，已全额退款 HK$X」+ 预计到账时间。不允许出现「不退」「扣手续费」之类文案，与后端规则一致。
### 4.4 好友助力页（被分享者）
- 打开链接直接看到发起人头像、商品、当前价、「帮 TA 砍一刀」。
- 未登录：点按钮先登录再回来；同一用户对同一活动只能助力一次，重复显示「你已经帮 TA 砍过啦」。
- 助力成功：动效 ≤ 800ms，显示砍了 HK$X，下方「我也要发起砍价」。
- 活动已结束：「该砍价已结束」，给「去看看其他砍价」。
接口：`/bargain-sessions/{id}`、助力、发起、购买以 `routers/bargain.py` 现有路径为准。

## 5. 返现（`screens/cashback.dart`）
### 5.1 首页
- 顶部两块并排：「可提现」大字（moneyPositive），「待确认」大字（moneyPending）。下方小字「累计已赚 HK$X」。
- 「提现」主按钮：可提现 < 提现门槛时置灰，下方一行「满 HK$50 可提现」（门槛取接口，不写死）。
- 明细列表，按时间倒序，每行：商户名、消费日期、返现金额、状态胶囊。状态文案：
  - 线下 pending：「再来一次即可到账」+ 倒计时「还剩 X 天」
  - 线上 pending：「预计 X月X日 到账」
  - confirmed/withdrawable：「可提现」
  - withdrawn：「已提现」
  - void：「已失效」，原因行：「90 天内未再次消费」「订单已取消」「订单已退货」
- 线下 pending 行置顶高亮一条规则提示（可关闭）：「90 天内在同一商户再次消费，上一笔返现即到账」。
### 5.2 提现页
- 金额输入（默认全部可提现，含「全部提现」），显示门槛和每日上限。
- 方式：转数快 / 银行转账；收款姓名必须与注册姓名一致，输入框下方灰字提示；姓名不一致时表单内联报错，不弹窗。
- 提交后跳「提现记录」，状态：处理中 / 已到账 / 失败（失败显示原因与重试）。
### 5.3 漏记返现申诉
- 入口：返现页右上角「没收到返现？」。表单：商户、订单号、消费时间、金额、凭证截图（≤ 3 张）、备注。
- 超过 30 天直接在日期选择器里禁用，并提示「消费后 30 天内可申请」。
- 提交后进入申诉列表，状态：已提交 / 审核中 / 已通过 / 未通过（含原因）。
接口：`GET /cashback`、`/cashback/transactions`、`POST /cashback/withdraw`、`GET /cashback/withdrawals`、`POST /cashback/missing`。用户端不再有「记返现」入口（该接口会被修复单删除）；返现只由核销自动产生，核销成功页可显示「本次返现 HK$X，待确认」。

## 6. 附近（`screens/nearby.dart`）
- 顶部地图/列表切换。默认列表，按距离升序；可切换 评分最高 / 最新。
- 地图视图：Google Maps，商户 marker 按分类着色，点 marker 弹底部小卡片（图、名称、评分、距离、「导航」）。
- 定位未授权：显示「开启定位查看附近商户」+ 按钮；拒绝后降级为按区域选择，不反复弹授权。
- 列表卡片：图、名称、分类、评分、距离（`320 米` / `1.2 公里`）、有券/有套餐标记。
- 「导航」调起系统地图，不在应用内做路线规划。

## 7. 评分与评价（`screens/reviews_admin.dart` 用户部分）
- 入口：仅在核销成功的券/套餐上显示「去评价」；未核销用户在商户页只能看评价，没有写评价按钮。
- 表单：口味/环境/服务三维 5 星（半星不支持），文字 ≤ 500 字，图片 ≤ 6 张。
- 评价积分与星级分开：提交成功后可显示「已获得 X 积分」，积分不影响商户星级；任何位置不写「好评赚积分」「评价有奖」。
- 商户页汇总：总分、三维分、星级分布条形图、带图评价筛选、「最新/最有用」排序。
- 差评（≤ 2 星）商户可在后台回复，用户端显示商户回复，样式缩进灰底。

## 8. 钱包与商户端小改
### 钱包
- 三栏 未使用 / 已使用 / 已失效；套餐券左上角「套餐」角标。
- 出示页：二维码居中，下方券名、有效期、门店；二维码有倒计时圈，到期自动换新码并闪一下提示；出示页亮度自动拉满，退出时恢复；禁止截屏提示文案「请勿转发二维码」。
- 核销成功后（轮询或推送）自动关闭二维码页，进入「核销成功」页：显示券名、门店、返现提示、「去评价」。
### 商户端（`screens/vendor.dart`）
- 扫码后两步：① 预核销页显示券名、顾客手机号后四位、有效期、是否已使用，底部「确认核销」；② 成功页显示「已核销」。
- 成功页 10 分钟内显示「撤销核销」，点击二次确认；超时按钮消失，不置灰。
- 扫到无效码/已使用/他店码：全屏红色结果页 + 原因，一个「继续扫码」按钮。
- 「核销记录」页支持日期筛选和导出 CSV。

## 9. 后台（Web，管理员/商户管理员）
首期做三块，列表 + 筛选 + 右侧详情抽屉，不先做图表：
1. 入驻审核：待审核列表、资质图片预览、通过/驳回（驳回必填原因）。
2. 订单：套餐订单、状态筛选、详情抽屉看支付/退款时间线、管理员退款需二次确认并写原因。
3. 结算（F 线合入后）：按商户、周期对账，导出 CSV。
权限：按角色隐藏菜单，同时接口侧校验；前端隐藏不等于授权。

## 12. 功能如何串联（按底部 5 个入口）

核心思路：一张「钱包」装所有券（领的券、买的套餐券、砍到的套餐券同一入口，同一出示页、同一核销）；一条「钱」线索只在 Q Wallet 里出现（积分、返现分开）；新玩法只是首页和限時上的入口，不新增主路径。

### 12.1 入口映射
| 底部入口 | 现有内容 | 加入的新功能 |
|---|---|---|
| 主頁 | 分类、熱門優惠券 | 顶部「限时砍价」横滑（最多 6 张）；「熱門套餐」2 列；「附近優惠」带距离 |
| 收藏 | 收藏的商户和券 | 加收藏套餐；商户有新套餐或新砍价时卡片出角标 |
| Let's Go! | 全部優惠、地區、分類 | 加「附近」标签（列表/地圖切换）；筛选加「套餐」「可返現」；只留一个搜索栏 |
| 限時 | 限时领券 | 分两段：「砍價」在上，「限時搶券」在下；我的进行中砍价置顶一条横幅 |
| Q Wallet | 積分、我的優惠券 | 标签：我的優惠券 / 返現 / 積分 / 訂單；券列表在最上，積分缩成一行 |

### 12.2 商户页作为交汇点
商户详情页自上而下：封面与评分 → 距离与导航 → 「套餐」横滑 → 「優惠券」→ 「可返現 X%」一行（点开说明规则）→ 评价摘要 → 门店。同一商户的券、套餐、砍价、返现、评价都在这一页，用户从任何入口进来都能看到全貌。

### 12.3 四条用户旅程（验收按这四条走）
1. 领券：主頁 → 領取 → Q Wallet 優惠券 → 出示 → 核銷成功页（显示「本次返現 HK$X · 待確認」）→ 去評價。
2. 套餐：主頁熱門套餐 → 套餐详情 → 確認支付 → 正在確認支付結果 → 成功页 → 券进入同一個 Wallet 優惠券（带「套餐」角标）→ 出示 → 核銷 → 评价。
3. 砍價：限時（或主頁橫滑）→ 活動详情 → 先付 → 我的砍價（进度）→ 分享 → 好友助力页 → 達底價或時間到 → 差額自动退回，券进 Wallet。
4. 返現：核銷後在 Wallet 返現标签出现一行「待確認」→ 90 天内同商户再次核銷，上一筆变「可提現」→ 提現 → 提現記錄。

### 12.4 展示规则（避免用户混淆）
- 三种东西三种样式：領取（描边按钮）= 免费或积分券；立即搶購（实心主色）= 套餐；去砍價（强调色实心）= 砍价。
- 钱与积分永不同屏相加：Q Wallet 顶部是两个并列数字，「HK$ 返現」用 moneyPositive/moneyPending 色加 HK$ 前缀，「積分」用中性色加「分」后缀，积分行不写金额，返现行不写分。
- 返现状态固定四个词：待確認 / 可提現 / 已提現 / 已失效，原因写一句人话。
- 套餐券和普通券在 Wallet 同列，仅角标不同；出示页、核销页、撤销规则完全一致。
- 评价入口只出现在已核销的券或订单上，积分提示不影响星级展示。
- 新功能暂未就绪时隐藏入口，不放占位。返现标签等 FIX-2/N1 合入且接口可用后再显示。
