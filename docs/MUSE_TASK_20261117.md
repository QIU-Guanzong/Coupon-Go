## M1【P0】到期自动退款与砍价结算必须自动跑
问题：套餐「过期自动退款」、砍价「时间到差额自动退回、未成团全额退款」是界面向用户承诺的文案，但代码里没有任何调度器。`POST /orders/process-expired-refunds` 和 `POST /bargain/expire-sweep` 只能管理员手动调用，不调就不退款。pending 订单 15 分钟关闭、返现 90 天作废也没有定时清扫（只在用户打开页面时顺带触发）。
要求
1. 加一个后台定时任务（进程内 APScheduler 或独立 worker 命令二选一，写明部署方式），周期执行：过期套餐退款、砍价到期结算、超时 pending 订单关闭、返现 sweep（全体用户，分批处理）。
2. 每个任务幂等，可重复执行；多实例部署时只有一个实例实际执行（Postgres advisory lock 或行锁）；单条失败不影响其他，失败写日志并保留重试。
3. 与手动接口共用同一份逻辑，手动接口保留给管理员补跑。
4. 非 dev 环境缺调度配置时启动给出明确提示，不静默不跑。
验收：造一张已过期套餐订单，不调手动接口，等一个周期后自动退款一次且只退一次；同上验证砍价到期、订单超时关闭；并发启动两个实例只执行一次。
